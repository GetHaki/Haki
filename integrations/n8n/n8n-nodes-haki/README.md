# n8n-nodes-haki

Moved to its own repository: **[GetHaki/n8n-nodes-haki](https://github.com/GetHaki/n8n-nodes-haki)**.

Why: the n8n Creator Portal's automated verification validates against a
known single-purpose repo structure and can't reliably locate a node
inside an arbitrary monorepo layout (confirmed directly by n8n's node
review team — the previous submission from this subdirectory kept
failing with "Can't find credential file in repo" despite the file being
present and correctly declared).

Package: [`n8n-nodes-haki` on npm](https://www.npmjs.com/package/n8n-nodes-haki).
